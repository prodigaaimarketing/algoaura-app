# AlgoAura for Android

This repository exists to **host the AlgoAura Android app for download**. There
is no source code here — the app is built from a private repository, and only
the finished `.apk` is published, as a release asset.

## Download

**[Download the latest APK](https://github.com/prodigaaimarketing/algoaura-app/releases/latest)**

Most people should not use this page. The app is offered, with installation
instructions, at:

**https://algoaura-ai.prodigainfinity.com/app**

## Installing

Android asks for permission before installing an app from outside the Play
Store. That prompt is normal for a direct download and appears for every app
distributed this way.

1. Open the downloaded file from your notifications or your Downloads folder.
2. If asked, allow **"Install unknown apps"** for your browser or Files app.
3. Tap **Install**, then sign in with your usual AlgoAura email and password.

The app is the same AlgoAura that runs in the browser, so your account and
settings are already there.

## Android only

There is no iPhone build. AlgoAura works in any mobile browser in the meantime.
